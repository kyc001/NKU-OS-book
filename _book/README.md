# 南开大学操作系统实验指导书（离线版）

本目录包含操作系统实验指导书的 HTML 页面及配套图片、样式和脚本。解压后即可阅读，无须安装实验工具链。

## 快速阅读

1. 将 ZIP 完整解压，保留 `_book` 内的目录结构。
2. 用浏览器打开 `_book/index.html`。
3. 通过左侧目录进入各实验；Lab1 也可直接打开 `lab1/lab1.html`。

请勿只复制单个 HTML 文件，页面需要同目录下的图片、样式和脚本。

## 推荐方式：启动本地网页服务

如果直接打开页面时搜索、导航或资源加载异常，可使用本地 HTTP 服务。需要电脑已安装 Python 3。

在解压后的 `_book` 目录打开终端：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Windows 如使用 Python 启动器，可运行：

```powershell
py -3 -m http.server 8000 --bind 127.0.0.1
```

保持终端打开，在浏览器访问 <http://localhost:8000/>。Lab1 地址为 <http://localhost:8000/lab1/lab1.html>。阅读结束后，在服务终端按 `Ctrl+C` 停止。

若提示端口被占用，可将命令中的 `8000` 改为 `8001`，并访问 <http://localhost:8001/>。

## 内容与使用范围

- `index.html`：指导书入口。
- `lab0/`、`lab0.5/`、`lab1/` 等目录：各章节内容，以首页目录为准。
- `appendix/`：附录。
- `gitbook/`、`styles/`：页面所需资源，请保留。

本压缩包仅包含指导书，不包含实验代码、个人报告或已经配置好的实验环境。阅读指导书不等于完成实验；实际操作仍需准备对应源码与工具。
